# Smart Vehicle Monitoring System

Arduino-based vehicle monitoring system developed as my CS50x final project.

## Features

- Temperature monitoring
- Fuel level monitoring
- Distance monitoring
- LED status indicators
- Buzzer alerts
- Push-button control
- Button debouncing

## Technologies

- Arduino
- C/C++
- Wokwi
- Embedded systems concepts

## Project

The system monitors basic vehicle conditions and provides visual and audio alerts based on sensor readings.
